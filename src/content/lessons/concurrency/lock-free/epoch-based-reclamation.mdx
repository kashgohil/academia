Hazard pointers protect individual nodes. **Epoch-based reclamation** (EBR, Keir Fraser, 2004) protects *time periods* instead. A global counter, the **epoch**, advances slowly. A thread entering an operation **pins** itself: it announces "I'm active in epoch e". Nodes retired in epoch e go into a bag labelled e. The epoch can only advance when every active thread has announced the current one. Once the global epoch is e + 2, nobody can still hold a pointer obtained in epoch e, so that bag is freed in one go.

The plot replays the same workload under three schemes, with T0 stalled after pinning or protecting. **Never free** grows linearly. **Epoch-based** tracks it exactly, because no bag can be freed. **Hazard pointers** stay under a handful of nodes.

## Step through it

<LockFreeStepper title="Treiber stack with epoch-based reclamation" scenario={EBR} scripts={EBR_SCRIPTS} scheme="epoch" />

1. Run **T0 pinned while T1 retires three nodes**. T1's attempts to advance the epoch fail at `check T0's epoch`, and its bags fill up.
2. Reset, run T0's whole pop first, then T1's three pops. With nobody pinned in an old epoch, T1's advance attempts succeed and the global epoch reaches 2. The bags still aren't freed by the end: a bag is emptied only when its owner next pins two epochs later. EBR frees lazily, in batches.
3. Count the steps per operation and compare with hazard pointers: pin, unpin and occasional advance attempts, but **no fence per node visited**.

## Correctness and cost

<StressDemo configs={STRESS_EBR} />

| | Hazard pointers | Epoch-based |
|---|---|---|
| Read-side cost | store + fence per protected pointer | one announcement per *operation* |
| Long traversals | expensive | cheap: any number of nodes inside one pin |
| Unreclaimed memory | bounded | unbounded if a thread stalls while pinned |
| Freeing | per-node scans | in bulk, by epoch |

That trade-off decides most real choices. EBR suits data structures where operations are short and threads don't block inside them: crossbeam-epoch underlies Rust's crossbeam channels and maps. Linux's RCU is the same idea, with "quiescent states" (a context switch means a CPU holds no RCU-protected pointers) instead of explicit epochs. Hazard pointers suit long-lived readers and systems that must bound memory. Hybrids exist (hazard eras, interval-based reclamation) to get EBR's speed with bounded memory.
