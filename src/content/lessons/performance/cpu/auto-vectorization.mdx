At `-O2` and `-O3` (or a Rust release build), LLVM and GCC try to change simple loops into SIMD code. When this works, you get the speedups of the previous lesson without extra work. When it does not work, the compiler does not tell you. The loop just stays scalar.

## When iterations can share a vector

A vector instruction runs several iterations at the same time. This is safe only if no iteration needs a result from another iteration in the same vector.

<LoopDependencyDemo />

1. Select **c[i] = a[i] + b[i]**. The iterations are independent. Each vector group is safe.
2. Select **a[i] = a[i-1] * k**. Each iteration needs the one before it. There are red arcs inside each group.
3. Select **a[i+2] = a[i] + 1**. With 4 lanes, the arcs are inside the groups. Set the lanes to 2: the arcs go between groups, and the loop is safe.
4. Select **a[i+8] = a[i] + 1**. With 8 lanes or fewer, it is safe.

1. Select **c[i] = a[i] + b[i]** without the no-overlap option. The compiler adds a runtime check for overlapping arrays. Rust slices and C `restrict` remove the check.
2. Select the sum and the conditional sum. Floats need permission to change the order. Integers do not.
3. Select the recurrence. It never vectorizes.
4. Select the gather, the early exit and the function call. These stop the vectorizer, or make it less useful.

## The four things that stop the vectorizer

| Problem | Example | Fix |
|---|---|---|
| Arrays can overlap | `void f(float *c, float *a)` | `restrict`; Rust references already guarantee no overlap |
| Dependency between iterations | prefix sums, `x = f(x)` | change the algorithm (parallel scan, blocking) |
| Float rules | reductions | `-fassociative-math`, several accumulators, or vector types |
| Unknown control flow | function calls, early exits | inline the function, move the condition, split search loops |

## How to check

- Clang and Rust: `-Rpass=loop-vectorize -Rpass-missed=loop-vectorize`. In Rust, use `RUSTFLAGS="-C remark=loop-vectorize -C debuginfo=1"`.
- GCC: `-fopt-info-vec-optimized` and `-fopt-info-vec-missed`.
- Read the assembly, for example on Compiler Explorer. `ymm` or `zmm` registers and `ps` instructions show vector code. `ss` instructions show scalar code.
- Set the target CPU: `-march=native` or `-C target-cpu=native`. The default x86-64 target allows only SSE2, so the compiler cannot use AVX2.

## Write loops that the compiler can vectorize

<Steps>
<div>Use simple counted loops over contiguous arrays. Slice iterators in Rust and Zig are fine.</div>
<div>Keep function calls that cannot be inlined, and early exits, out of the loop body.</div>
<div>Make sure that no iteration reads a value that a later iteration writes.</div>
<div>For float reductions, allow a different order, or write the accumulators yourself.</div>
<div>Store each field in its own array (struct of arrays).</div>
</Steps>
